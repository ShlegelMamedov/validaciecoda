# validaciecoda

1. Основная цель валидации ввода?
Предотвратить ошибки программы, защитить от некорректных/вредоносных данных, обеспечить целостность и безопасность приложения, улучшить пользовательский опыт за счёт понятных сообщений об ошибках.
2. Для чего нужна конструкция try...except?
Для обработки исключений (ошибок) во время выполнения: программа не завершается аварийно, а переходит в блок except, где можно вывести понятное сообщение или предпринять действия для восстановления.
3. Разница между else и finally в try...except?
else выполняется только если в try не произошло исключений. finally выполняется всегда — независимо от того, была ошибка или нет (удобно для закрытия файлов, соединений и т.п.).
4. Какое исключение возникает при int("abc")?
ValueError — возникает, когда функция получает аргумент правильного типа, но недопустимого значения (строка не может быть преобразована в число).
5. Как организовать повторный запрос ввода?
Использовать while True: + break внутри else или после успешной проверки. Цикл продолжается, пока не выполнится break при корректном вводе.
6. Зачем регулярные выражения в валидации?
Для проверки формата строки по сложным шаблонам: email, телефон, ИНН, пароль, дата и т.д. Позволяют одной строкой кода проверить соответствие ввода заданным правилам.
